#MUSIC_ME

##Features

###It consists of a CRUD system where you can add data about music (title, duration, artist, year)
###It implements relationships between entities (ManyToOne)
###The system automatically detects whether an artist is already registered using dynamic queries. If duplicate profiles with the same name exist, it provides an interactive selection menu to prevent data redundancy without requiring the user to memorize relational IDs.

##Technologies Used

* **Language:** Java
* **ORM / Persistence Framework:** Hibernate / JPA
* **Database:** MySQL
* **Dependency Manager:** Maven
* **Recommended IDE:** IntelliJ IDEA
